# 📝 Flask To-Do App

A simple and modern To-Do List web application built using **Python Flask** and **SQLite**.  
Supports adding tasks, deleting tasks, and marking tasks as **completed** with a checkbox.

This project is perfect for learning:
- Python Flask basics  
- CRUD operations  
- HTML templates (Jinja2)  
- SQLite database  
- Static file handling (CSS)  
- Building your first backend web app  

---

## 🚀 Features

✔ Add new tasks  
✔ Delete tasks  
✔ Mark tasks as **completed**  
✔ Completed tasks show green background + strike-through  
✔ Modern UI with CSS  
✔ Smooth animations  
✔ Fully responsive layout  
✔ Beginner-friendly code structure
